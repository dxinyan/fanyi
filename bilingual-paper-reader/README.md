# 论文双语精读器

对应上游项目：**Bilingual-Paper-Reader**

GitHub：https://github.com/fff0301/Bilingual-Paper-Reader

## 定位

把英文论文 PDF 转换成适合阅读的双语 HTML：英文原文保留，中文翻译紧跟在对应英文句子下面。

## 适合谁

- 阅读英文科研论文
- 希望保留英文原文进行对照
- 希望按句子理解，而不是只得到一份纯中文译文
- 需要在手机或浏览器中阅读论文

## 主要特点

- 英文原文 + 中文翻译逐句对应
- 摘要和正文自然语言段落翻译
- 公式、图片、表格等内容尽量保持原样
- 可生成单个 HTML 文件
- 支持对部分 PDF 文本问题进行修复

## 上游运行方式

请以原项目 README 的最新说明为准。该项目需要 Python 环境以及 MinerU、OpenRouter 等外部服务/API 配置。
