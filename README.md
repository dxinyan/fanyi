# 双语翻译工具集

这个仓库整理两款适合“保留英文原文 + 中文译文对照阅读”的工具。

## 工具分类

### 1. 论文双语精读：Bilingual-Paper-Reader
- 适用：英文论文 PDF
- 形式：英文句子下面紧跟中文翻译
- 特点：适合逐句精读，并提供段落级中文解释
- 目录：[bilingual-paper-reader](./bilingual-paper-reader)
- 上游项目：https://github.com/fff0301/Bilingual-Paper-Reader

### 2. PDF 双语排版：translate-academic-paper
- 适用：学术论文、PDF 专著
- 形式：可切换原文 / 中英对照 / 纯中文
- 特点：更强调 PDF 页面、图片、公式和双栏论文版式的保留
- 目录：[translate-academic-paper](./translate-academic-paper)
- 上游项目：https://github.com/Zaious/translate-academic-paper

## 怎么选？

| 需求 | 推荐 |
|---|---|
| 一句英文下面看一句中文 | Bilingual-Paper-Reader |
| 做成完整的中英对照论文阅读页面 | translate-academic-paper |
| 重点是论文精读和中文解释 | Bilingual-Paper-Reader |
| 重点是 PDF 原版式、图片、公式和多种阅读模式 | translate-academic-paper |
