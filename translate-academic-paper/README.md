# PDF 学术论文双语翻译

对应上游项目：**translate-academic-paper**

GitHub：https://github.com/Zaious/translate-academic-paper

## 定位

将学术论文或人文学术专著 PDF 转换成自包含 HTML，并提供原文、中文以及中英对照阅读模式。

## 主要特点

- 纯中文 / 中英对照 / 纯原文三种阅读模式
- 尽量保留图片、公式和原 PDF 页面信息
- 支持双栏论文的版式还原
- 对扫描 PDF 提供 OCR/页面图像处理能力
- 可生成自包含 HTML，便于离线阅读
- 可选输出 Word 文档

## 适合谁

如果你最看重“论文原文版式 + 中文翻译 + 对照阅读”，优先使用这个项目。

## 上游运行方式

请以原项目 README 的最新说明为准。该项目属于脚本/Agent 工作流，不是普通 Chrome 一键安装插件。
